Adds `phu:` icons for 19 official parcel/postal carriers: InPost, DHL Express, Australia Post, La Poste, Spring GDS, DHL Paket, NZ Post, Swiss Post, Poczta Polska, Sameday, SunYou, Bring, Austrian Post, An Post, Omniva, CTT, Japan Post, Mondial Relay, and J&T Express. Each icon is traced from a real, distinguishing mark in that carrier's own official branding.

None of these have a Home Assistant integration yet. They're all on the research list [ha-parcel-integrations](https://github.com/ha-parcel-integrations) is currently working through (see [this discussion](https://github.com/orgs/ha-parcel-integrations/discussions/3) — @peternijssen has researched ~40 carriers so far and is looking for real-world data to build out support for as many as possible). [hki-parcels-card](https://github.com/jonisnet/hki-parcels-card) is pre-staging support for that same list so the card is ready as soon as (or before) each integration ships, and it seemed worth doing the same here — as a side effect, having these carriers show up with proper branding in tools like this one may also help that project get noticed and gather the data it's after sooner, but the icons stand on their own regardless: these are all real, official carriers that just don't have an icon here yet.

**Not included**: FedEx, Royal Mail, and USPS already have an icon here. Poste Italiane, Econt, Quickpac, Planzer, and PostNord are also on the same research list but their real branding is wordmark-only — none of them has a standalone icon/symbol to trace. Rather than submit a made-up letterform as if it were their brand mark, I've left those out for now; happy to open a separate discussion on what convention this repo would prefer for wordmark-only brands before proposing anything for those five.
